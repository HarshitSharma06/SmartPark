# SmartPark – Smart Parking System

## Project Overview
SmartPark is an Android application designed to help users find parking locations more conveniently. It provides a simple interface for exploring parking information and accessing parking-related features.

## Features
- Parking location discovery
- Map-based parking interface
- Parking lot details
- User login and signup screens
- Saved parking locations
- Parking occupancy prediction
- Local data storage using SQLite
- Parking history and user preferences

## Technologies Used
- **Language:** Java
- **UI:** Android XML layouts
- **Database:** SQLite
- **Platform:** Android Studio
- **Location and Maps:** Project location and map components
